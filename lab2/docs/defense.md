# Подготовка к защите: Джилб и Маккейб

## Что делает работа

`example.ts` — программа на TypeScript, которая накапливает сумму в разных ветвях и циклах. Она содержит обычный for, while, do-while, for-in, for-of, if без else, if/else, switch из четырёх case и default внутри if. В первом, а не последнем case расположен ещё один if. Вывод при запуске: `total = 20`. Разбор статический: даже недостижимые при выбранных константах ветви остаются частью исходной структуры.

`analyzer.ts` получает от TypeScript Compiler API синтаксическое дерево и обходит операторы тела функций. `index.html` предоставляет графический интерфейс непосредственно в браузере. Приложение не запускает введённый TypeScript: выполнение примера и анализ структуры — разные операции.

## Джилб

Метрика оценивает насыщенность программы ветвлениями и их максимальную вложенность.

- **CL** — абсолютная сложность, число ветвлений в исходной структуре. В данной работе учитываются if, каждый цикл и каждый case; условное выражение `?:` также считается решением.
- **cl = CL/N** — относительная сложность, где N — число операторов. В N входят самостоятельные выражения, объявления переменных, управляющие операторы и переходы. Блоки, метки, типы и объявления функций не учитываются; тела функций анализируются. Заголовок for входит в один оператор цикла. Несколько case на один оператор или несколько `?:` в выражении могут дать отношение больше 1.
- **CLI** — максимальный уровень вложенности ветвлений; первое ветвление находится на уровне 0. Последовательные if имеют глубину 0, вложенные — 0, 1, 2 и т. д. При отсутствии ветвлений CL=CLI=0. При N=0 отношение cl математически не определено.

Цикл считается один раз независимо от количества итераций. do-while — один цикл, завершающий while не является вторым циклом. else не проверяет условие. Конструкция else if содержит новый if на вложенном уровне. Число логических частей условия само по себе не увеличивает CL этого профиля.

### Switch

Для CL и CLI представляем проверки case как вложенные if/else-if. Селектор вычисляется один раз и не является дополнительным решением. Default не добавляет условие. Его содержимое может содержать собственные ветвления — они учитываются.

Если switch начинается на глубине d и имеет k case, глубины сравнений: d, d+1, …, d+k−1. Уровень тела j-го case: d+j (j начинается с 1). Тело default находится после всех k сравнений. Поэтому независимый switch с четырьмя case и default даёт CL=4, CLI=3.

В нашем коде внешний for имеет глубину 0, if — 1, case — 2, 3, 4, 5. Внутренний if первого case находится на уровне 3. Максимум — 5, а не 6: нельзя ко всему switch прибавлять максимальную вложенность его произвольного тела. Если перенести этот if в четвёртый case, его глубина станет 6.

### Ручной результат

CL = 5 циклов + 3 if + 4 case = **12**.

N = 5 объявлений + 15 выражений + 3 if + 5 циклов + 1 switch + 4 break = **33**.

cl = 12/33 = **0,363636…**, CLI = **5**. Проверка CL > CLI: 12 > 5.

`let i=0` в заголовке for не является отдельным Statement и не входит в пять объявлений. Объявления — total, values, labels, j, k. Условие и шаг заголовка тоже не самостоятельные операторы. Вспомогательные r, t и keys раскрытых циклов на схеме в N не добавляются. Несколько переменных одного объявления считаются одной единицей. TypeScript использует грамматику управления ECMAScript, поэтому правило init-statement из C++ сюда не переносится.

Плюсы Джилба: простой расчёт, видны насыщенность решениями и глубокая вложенность. Ограничения: результат зависит от правил языка и соглашений; сложность данных, выражений, взаимодействия функций и предметной области описывается слабо. Добавление линейных операторов уменьшает cl, хотя структура решений может не измениться.

## Маккейб

Цикломатическая сложность оценивает число линейно независимых путей в графе потока управления (CFG). Узел представляет блок последовательных действий или проверку, дуга — возможную передачу управления. Линейно независимый путь добавляет направление перехода, которое не выражается комбинацией уже выбранных путей.

Для одного связного CFG с нормализованными входом и выходом:

**V(G) = E − V + 2**, где E — дуги, V — вершины. Для P отдельных компонент, представляющих такие графы функций: **E − V + 2P**. Это не обычный ранг циклов произвольного неориентированного графа E−V+P: в программе учитывается замыкание выхода на вход.

При только бинарных решениях: **V(G) = D + 1**. Для многовыходного узла вклад равен числу его исходов минус один. В связном планарном изображении CFG сложность равна числу областей, включая внешнюю. Число областей нельзя считать по произвольному рисунку с пересекающимися рёбрами как по независимым решениям.

V(G) задаёт размер базиса путей для структурного тестирования, но не число всех путей и не гарантию достаточного количества тестов. При циклах число возможных трасс может быть бесконечным; зависимости условий делают некоторые структурные пути невыполнимыми. Низкая V(G) не гарантирует отсутствие ошибок. Высокая — повод рассмотреть разбиение функции, а не доказательство её неправильности. Часто цитируемый порог 10 — рекомендация, не закон.

Для нашего структурного графа с четырьмя бинарными проверками switch D=12, поэтому V(G)=13. Это теоретическая иллюстрация: приложение реализует только Джилба. Для графа, раскрывающего короткое замыкание `&&`/`||`, количество решений может увеличиться. Не переносите формулу CL+1 на любой код без определения CFG.

Различие: CL считает ветвления принятой модели, cl нормирует их по операторам, CLI выделяет глубину, а V(G) характеризует структуру независимых путей. Две программы могут иметь одинаковую V(G), но разную вложенность.

## Тренировка перед защитой

1. `let x=0; console.log(x);` → CL=0, N=2, CLI=0, cl=0.
2. `if(x)++x; if(x>1)--x;` → CL=2, N=4, CLI=0, cl=0,5.
3. `if(x){if(x>1)++x;}` → CL=2, N=3, CLI=1, cl=2/3.
4. `for(let i=0;i<3;++i){}` → CL=1, N=1, CLI=0. Инициализация, условие и шаг — части for, а не отдельные statements.
5. Switch из четырёх case, каждый с break, без default → CL=4, N=5, CLI=3. Добавление default с break меняет N до 6, но CL/CLI остаются 4/3.
6. В предыдущий вариант без default добавить `if(x)++x;` в первый case → CL=5, N=7, CLI=3. В четвёртый case → CL=5, N=7, CLI=4.
7. Пустая `function f(){}` → CL=0, N=0, CLI=0, cl не определено.
8. `const f=(x:number)=>x?1:2;` → CL=1, N=2, CLI=0: объявление f и неявный return. Тело функции начинает отсчёт вложенности заново.
9. `for(const x of values) console.log(x);` перебирает значения; `for(const key in labels) console.log(key);` — перечисляемые строковые ключи. Каждый пример: CL=1, N=2, CLI=0. Тип итерации влияет на алгоритм, но каждый цикл даёт одно ветвление.

Порядок расчёта: выделить функции и операторы; перечислить if, циклы, case; представить switch цепочкой вложенных if; определить уровень каждого ветвления и взять максимум; посчитать N; разделить CL на N. Комментарии, строки, else, default и завершающий while в do-while не добавляют ветвлений.

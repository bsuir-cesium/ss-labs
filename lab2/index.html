Правила подсчёта и границы поддержки

CL — if, циклы, каждый case и условное выражение ?:; cl = CL/N; CLI — максимальная глубина с нуля.


Switch заменяется цепочкой вложенных if. Селектор, else и default не добавляют условий. Собственные ветвления внутри default учитываются. Четыре case без внешних ветвей: CL=4, CLI=3.


В N входят самостоятельные выражения, объявления переменных, управляющие операторы и переходы. Скобки, метки, типы и заголовки функций не добавляются. Инициализация и шаг for — части цикла. Несколько переменных одного объявления — одна единица. ASI учитывается парсером.


У каждой функции своя вложенность с нуля. Для стрелочной функции с выражением учитывается неявный return. При N=0 значение cl не определено. Несколько case или ?: на один оператор могут дать CL/N больше 1.


Поддержаны if/else, for, for-in, for-of, while, do-while, switch, функции, переменные, выражения, break/continue/return/throw. Классы, методы объектов, try/catch/finally, генераторы, метки, namespace/enum и tagged templates вызывают ошибку. &&, ||, ?? и optional chaining не считаются дополнительными решениями этого профиля.
